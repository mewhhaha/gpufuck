        What this demonstrates. The tour covers compile-time values,
        structural types, recursion, pattern matching, loops, effects and handlers, linear ownership,
        records, arrays, operators, and host capabilities. The other examples isolate those features.
        The stress project keeps hundreds of functions reachable across 25 modules so the
        phase timings show scaling separately from browser and GPU startup costs.
      

      

        Baba’s strict GPU frontend performs lexing, delimiter matching, island parsing, and flat
        syntax allocation. That result is currently the syntax gate; Blot repeats parsing with its
        cursor-producing Wasm parser because its AST lowerer does not yet consume Baba’s flat GPU IR.
        Blot’s comptime evaluator, algebraic-subtyping checker, and ownership pass remain on the CPU;
        gpufuck independently resolves and infers the lowered Core on the GPU.
