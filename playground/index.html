        What to expect. A small module here is almost all fixed cost — one GPU
        readback, measured at about 11 ms under Deno and unmeasured in browsers, so a 200-byte example
        tells you nothing about the compiler. Pick the generated stress example, or raise the
        batch count, to see per-module cost instead of that floor.
      

      

        On one large real program — Gleam’s standard library, 17,718 nodes — this pipeline is
        3.0× slower than gleam build, down from 27× earlier
        the same day. Batching is where it wins: a thousand independent modules compile about
        17× faster than a compiler with no cross-package batching. Every number,
        including the ones that turned out to be wrong, is in BASELINE.md.
